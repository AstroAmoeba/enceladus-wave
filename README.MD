# Propagación de ondas elásticas en la capa de hielo de Encelado

Análisis teórico de reflexión-transmisión y validación numérica simplificada con TauP y Deepwave.

## Estado

desafortunado :c

## Estructura

- `docs/` — Documento o documentos con notas sobre el tema
- `src/` — Código fuente en python
- `notebooks/` — Exploración interactiva con Jupyter
- `meta/` — Boceto de propuesta, tareas por hacer, bitácora.

quizasmente
- `data/` — Datos y modelos 1D
- `results/` — Figuras y tablas generadas

## Instalación


```
git clone https://github.com/AstroAmoeba/enceladus-wave
cd encelado-sismologia
pip install -r requirements.txt
```
